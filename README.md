# 🚀 Arnav Sharma - 3D Developer Portfolio

A modern, luxury-inspired, and fully responsive personal portfolio website showcasing my journey as a Computer Science Engineering (Artificial Intelligence) student, developer, and technology enthusiast.

This portfolio highlights my work in Artificial Intelligence, Software Development, Cybersecurity, Data Analytics, Full Stack Development, and Prompt Engineering through an immersive user experience featuring modern UI/UX, interactive project showcases, certifications, technical skills, hackathons, and achievements.

## ✨ Features

* Modern Luxury UI/UX
* Fully Responsive Design
* Interactive Project Showcase
* Skills & Proficiency Dashboard
* Certifications & Achievements Section
* Education Timeline
* Hackathons & Workshops Showcase
* Contact & Social Integration
* Smooth Animations and Transitions
* Recruiter-Friendly Layout

## 🛠 Tech Stack

* React.js
* Next.js
* TypeScript
* Tailwind CSS
* Framer Motion
* Three.js / React Three Fiber
* Git & GitHub

## 🎯 Purpose

Designed to create a strong digital presence while showcasing technical expertise, academic achievements, projects, certifications, and extracurricular involvement in a visually engaging and professional manner.
